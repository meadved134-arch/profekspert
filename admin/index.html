Уведомления в Telegram (Рекомендуется)

Получается у официального бота @BotFather
Ваш ID от @userinfobot или ID группы (начинается с минуса)
📖 Инструкция: Как создать и подключить Telegram-бота (по шагам)
  1. Создать бота: Откройте бота @BotFather в Telegram, отправьте команду /newbot, задайте имя и юзернейм (например, profexpert_leads_bot). Скопируйте выданный API Token в поле выше.
  2. Узнать ваш Chat ID: Откройте бота @userinfobot (или @getmyid_bot) и нажмите «Запустить». Скопируйте число из строки Id в поле выше.
  3. Активировать бота: Обязательно откройте вашего созданного бота в Telegram и нажмите «Запустить» (/start).
  4. Для группы компании: Создайте группу, добавьте туда бота, сделайте админом, добавьте @userinfobot (чтобы узнать ID группы, он начинается с минуса, например -1001234567890) и укажите этот ID в поле.
✉️

Уведомления на Почту (SMTP)

Можно указать несколько адресов через запятую
Почтовый ящик, с которого отсылаются письма
Специальный пароль для программ из настроек безопасности
📖 Инструкция: Как получить пароль приложения для почты (Яндекс / Mail.ru / Хостинг)
  • Яндекс Почта / Яндекс 360: Перейдите в id.yandex.ru/security ➔ раздел «Пароли приложений» ➔ нажмите «Создать пароль» ➔ тип «Почта». Скопируйте 16-значный пароль. Сервер: smtp.yandex.ru, Порт: 465.
  • Mail.ru / VK WorkSpace: Перейдите в account.mail.ru/user/security ➔ «Пароли для внешних приложений» ➔ «Добавить». Сервер: smtp.mail.ru, Порт: 465.
  • Почта на хостинге (Timeweb, Beget, Reg.ru): Создайте ящик в панели хостинга (например, info@vash-domen.ru) и укажите SMTP-сервер хостинга, порт 465 и обычный пароль от ящика.
