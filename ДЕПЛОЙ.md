# Памятка по серверу и деплою сайта «ПрофЭксперт»

## Данные сайта и сервера
- **Основной домен:** [https://profekspert.site](https://profekspert.site) 🔒 (с замочком SSL)
- **Панель управления (админка):** [https://profekspert.site/admin/](https://profekspert.site/admin/)
- **Прямой IP-адрес сервера:** `79.174.85.179`
- **Хостинг:** Рег.облако (Reg.ru, Москва)
- **Операционная система:** Ubuntu 24.04 LTS
- **Путь к сайту на сервере:** `/var/www/profexpert`
- **Веб-сервер:** Nginx (порты 80 и 443 HTTPS с автоматическим редиректом)
- **Сертификат безопасности:** Let's Encrypt (автоматически обновляется)
- **Менеджер процессов:** PM2 (процесс `profexpert`, Python 3 на порту 8085)
- **База данных:** SQLite (`/var/www/profexpert/database.db`)
- **Уведомления о заявках:** Мессенджер Max (max.ru), Telegram, Email

## Как подключаться к серверу
На твоём компьютере настроен короткий псевдоним (алиас). Достаточно открыть терминал / PowerShell и ввести:
```bash
ssh mysite
```
*(или напрямую: `ssh root@79.174.85.179`)*. Вход происходит автоматически по электронному ключу без ввода пароля.

> [!CAUTION]
> Файл твоего приватного ключа `~/.ssh/id_ed25519` хранится только у тебя на компьютере. Никогда и никому не передавай его и не загружай в открытые репозитории.

## Как обновлять сайт одной командой
Когда ты или ассистент внесли изменения в код сайта:
1. Запусти команду обновления:
   - На Windows: `powershell -ExecutionPolicy Bypass -File .\deploy.ps1`
   - Или в Git Bash / Linux / Mac: `bash deploy.sh`
2. Скрипт сам зайдёт на сервер, подтянет свежий код и перезапустит сайт за 3 секунды.
