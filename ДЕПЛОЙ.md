## Как подключаться к серверу
На твоём компьютере уже настроен короткий псевдоним (алиас). Достаточно открыть терминал / PowerShell и ввести:
```bash
ssh mysite
```
*(или напрямую: `ssh root@79.174.85.179`)*. Вход происходит автоматически по электронному ключу без ввода пароля.

> [!CAUTION]
> Файл твоего приватного ключа `~/.ssh/id_ed25519` хранится только у тебя на компьютере. Никогда и никому не передавай его и не загружай в открытые репозитории.

## Как обновлять сайт одной командой
Когда ты или ассистент внесли изменения в код сайта:
1. Запушьте изменения на GitHub (`git push`).
2. В терминале в папке проекта запустите:
   - На Windows: `powershell -ExecutionPolicy Bypass -File .\deploy.ps1`
   - Или в Git Bash / Linux / Mac: `bash deploy.sh`
3. Скрипт сам зайдёт на сервер, подтянет свежий код и перезапустит сайт за 3 секунды.

## Подключение домена (например, profexpert76.ru)
Когда решишь привязать красивый домен:
1. В панели управления доменом (где он куплен) в разделе **DNS-записи** добавь **A-запись**:
   - **Имя (хост):** `@` (или пусто)
   - **Значение (IP):** `79.174.85.179`
   - Для поддомена `www`: имя `www`, значение `79.174.85.179`
2. После того, как DNS обновятся (обычно от 15 минут до нескольких часов), зайди на сервер и подключи бесплатный SSL-сертификат (https) одной командой:
   ```bash
   certbot --nginx -d твойдомен.ru -d www.твойдомен.ru
   ```
